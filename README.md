登录时校验只比对了签名，没管计数器，攻击者把一次合法的断言原样重放，每次都能通过：签名计数器必须单调递增；计数器回退或不变都必须视为克隆并拒绝；挑战必须一次性；来源与依赖方标识必须精确匹配；签名必须覆盖认证数据与客户端数据摘要；公钥必须来自注册时记录的那一把；批量校验各断言独立。不变量：同一断言第二次使用必然失败；计数器只增不减。

运行

python -m pytest tests -q
